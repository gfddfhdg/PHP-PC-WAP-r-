# PHP开发的人才招聘系统源码/招人系统/人才系统/兼职全职招聘PC/WAP/公众号开源版

源码地址：ym7k.com/19348/

## 🧱 技术与环境

- **后端**：PHP + MySQL，主流框架 TP5 / TP6（74CMS、PHPYUN 是独立自研 PHP 招聘框架）
- **端口**：PC 主站、WAP 手机站、微信公众号 H5（公众号授权登录、消息推送）、PC 企业后台、总管理后台
- **环境**：PHP7.2–7.4、Nginx、伪静态、Redis（可选）、微信公众号、短信、微信支付
- **特点**：原生网页体系，公众号直接接入，不用单独小程序前端（可额外对接小程序接口）

## 🧑‍💼 求职者端（PC / WAP / 公众号）

- 账号注册、微信公众号一键授权登录、实名
- 标准简历：基础信息、教育、工作经历、项目、证书、求职意向；简历隐身、屏蔽企业
- 岗位筛选：城市、行业、薪资、学历、经验、全职 / 兼职 / 实习 / 远程
- 岗位收藏、一键投递、批量投递、投递记录、面试邀约、面试日程
- 人才主页，企业可主动检索邀约；简历下载权限控制
- 公众号消息推送：岗位推荐、面试通知、HR 回复提醒
- 在线留言、隐私号码保护

## 🏢 企业端（PC + 公众号 H5）

- 企业入驻、营业执照审核，支持多 HR 子账号
- 发布岗位：岗位职责、任职要求、福利标签、招聘人数、有效期，区分全职 / 兼职
- 人才库筛选检索、简历查看、标记面试状态（待沟通、面试、录用、淘汰）
- 岗位上下架、暂停、刷新、置顶、加急推广
- 企业主页、企业相册、在招岗位展示、简历导出
- 充值购买会员、简历点数、推广套餐，公众号内直接支付

## 🧑‍💻 PC 总后台

- 用户、企业、岗位、简历审核，敏感词、举报、黑名单
- 地区、行业、岗位分类、福利标签后台自定义
- **多城市分站（热门选配）**：分站独立后台、独立广告、独立套餐定价、分佣
- 变现体系：企业会员、简历下载扣费、职位置顶刷新、招聘会展位、广告位
- 财务模块：充值订单、流水、提现对账、退款记录
- SEO 全套：栏目、列表、详情独立标题 / 关键词 / 描述、伪静态、百度推送
- 招聘会模块：线上双选会、宣讲会、预约报名、签到
- 猎头 / 经纪人模块：猎头入驻、人才推荐拿赏金
- 权限分级：运营、财务、客服、分站管理员
